# Britecharts React — archived

This repository is the pre-monorepo `britecharts-react` package. It is frozen
and archived; `@britecharts/react` in the Britecharts monorepo is its
successor:

https://github.com/britecharts/britecharts/tree/main/packages/react

The unscoped `britecharts-react` package on npm is deprecated — install
`@britecharts/react` instead:

```sh
yarn add @britecharts/react @britecharts/core @britecharts/wrappers
```

The code in this repository targets `britecharts-react@0.6.5` and is kept
only for history.
